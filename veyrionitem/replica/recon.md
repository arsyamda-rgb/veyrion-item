# Recon: ItemsAdder-style custom content plugin (written from domain knowledge, not from the original's code)

Target behaviour: a Paper plugin where admins define custom items, blocks, furniture, font images and GUIs in
YAML, and the plugin builds the matching resource pack.

Sources: public ItemsAdder documentation and general Minecraft resource pack knowledge. No decompiling, no
copied assets, own config format and own names.

Not run yet: /replica-recon, /replica-design. This file stands in for them.
